## Updating safely

1. Edit native text and image alt text together when changing a product.
2. Keep section anchors in the navigation synchronized with the headings.
3. Render through GitHub's Markdown API or GitHub's Preview tab.
4. Check the actual GitHub profile at desktop and mobile widths. Expand the details sections and verify image and destination links.
5. Commit the README and any changed local assets together.

GitHub controls fonts, spacing, theme, and responsive behavior for native Markdown. The banner preserves the editorial typography; the rest intentionally follows GitHub's accessible text rendering. All images are hosted in this repository.
